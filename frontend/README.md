# Cumilla Press Club Public UI

React + Vite + Tailwind CSS homepage UI for the public website.

## Sections Included

- Top header with Bangla/English date-time, login button, dark/light toggle
- Logo/title and sponsor banner area
- Navigation menu
- Breaking news ticker
- Featured and category blocks
- Notice board with PDF download buttons
- Leadership message and executive committee grid
- Media gallery section
- Member verification search area
- Footer with links, contact, social and copyright

## Run

1. Open terminal in frontend directory
2. Install dependencies
3. Start dev server

Commands:

npm install
npm run dev

Build command:

npm run build

If npm install fails due network/proxy, configure npm proxy and retry.
